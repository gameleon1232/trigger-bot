# Автокликер с графическим интерфейсом

Красивый автокликер с настройками и предпросмотром области захвата.

> English summary: a color-trigger autoclicker for Windows. Hold **Alt** to memorize the average color of a screen region — when it changes beyond the tolerance, the app clicks. Two implementations: Python (console + Tkinter GUI) and C++ (Win32/GDI, CMake).

## Возможности

- 🎯 **Предпросмотр области захвата** - визуально отображает область, которую отслеживает программа
- ⚙️ **Гибкие настройки** - координаты центра, радиус области, погрешность цвета
- 💾 **Сохранение настроек** - автоматическое сохранение и загрузка конфигурации
- 🎨 **Современный интерфейс** - темная тема с удобным управлением
- 📊 **Информационная панель** - отображение статуса и захваченного цвета

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Запустите программу:
```bash
python auto_clicker_gui.py
```

## Использование

### Основные элементы интерфейса:

**Левая панель - Настройки:**
- **Координаты центра (X, Y)** - позиция точки отслеживания на экране
- **Радиус области** - размер области для усреднения цвета (1-20 пикселей)
- **Погрешность (%)** - допустимое изменение цвета (0-50%)

**Правая панель - Предпросмотр:**
- Живое изображение области вокруг точки отслеживания
- Красная рамка показывает границы области захвата
- Информация о захваченном цвете

### Как использовать:

1. **Настройте параметры** в левой панели
2. **Нажмите "Запустить"** для начала работы
3. **Зажмите Alt** для захвата цвета в указанной области
4. **Отпустите Alt** для остановки отслеживания
5. **Нажмите "Остановить"** для полной остановки программы

### Сохранение настроек:

- **"Сохранить настройки"** - сохраняет текущие параметры в файл
- **"Загрузить настройки"** - восстанавливает ранее сохраненные настройки

## Файлы

- `auto_clicker_gui.py` - основная программа с графическим интерфейсом
- `auto_clicker.py` - оригинальная консольная версия
- `requirements.txt` - зависимости для установки
- `autoclicker_settings.json` - файл с сохраненными настройками (создается автоматически)

## Переписанная C++ версия

Добавлена быстрая реализация на C++ с консольным и GUI-приложением (Win32 + GDI):

- `cpp/src/AutoClickerConsole.cpp` — консольная версия (горячая клавиша Alt, усреднение цвета и клик)
- `cpp/src/AutoClickerGUI.cpp` — Win32 GUI с предпросмотром области, старт/стоп, сохранение/загрузка настроек
- `cpp/CMakeLists.txt` — сборка через CMake

### Сборка (Windows)

1. Установите CMake и MSVC (Visual Studio или Build Tools)
2. В корне проекта выполните:
```bash
cmake -S cpp -B build -G "Visual Studio 17 2022"
cmake --build build --config Release
```

Исполняемые файлы появятся в `build/Release/`:

- `AutoClickerConsole.exe`
- `AutoClickerGUI.exe`

GUI версия читает и пишет `autoclicker_settings.json` в текущей рабочей папке (UTF-8), как и Python-версия.

### Альтернатива: MinGW-w64 (g++)

Если нет CMake/Visual Studio, можно собрать так:

```bash
g++ -std=c++17 -O2 cpp/src/AutoClickerConsole.cpp -o AutoClickerConsole.exe -lgdi32 -luser32
g++ -std=c++17 -O2 cpp/src/AutoClickerGUI.cpp -o AutoClickerGUI.exe -lgdi32 -luser32 -lcomctl32 -lwinmm -mwindows -municode
```

### Оптимизация производительности

- Включена высокая частота таймера (1мс) и повышенный приоритет потока для минимальной задержки.
- Захват экрана реализован через кэшированный DIB Section без лишних аллокаций.
- Сравнение цветов — через целочисленный порог без float.
- Предпросмотр обновляется ~30 FPS.

## Примечания

- Программа работает в отдельном потоке, не блокируя интерфейс
- Предпросмотр обновляется в реальном времени
- Все настройки сохраняются в JSON файл
- Поддерживается работа с любым разрешением экрана

## Требования

- Windows (для корректной работы с захватом экрана)
